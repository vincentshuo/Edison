现在正是建造的黄金时代

Why Now Is The Golden Age of Building — Brian Armstrong (Coinbase), Founders, 2026

Speaker: Brian Armstrong, Coinbase 联合创始人兼 CEO；主持 David Senra, Founders 播客

Event: Founders 播客对谈

Length: 60 分 28 秒

Source: youtu.be/NuoEkfIkKX4

Technical Monograph · 精读报告 发布 2026 年 11 月 18 日 生成 2026 年 11 月 19 日

一小时的对谈，讲的是 Coinbase 创始人 Brian Armstrong 如何用 AI 重新组织自己的工作、以及他眼中正在成形的 Agent 经济。开场从一句写下来的话讲起：Tobi Lütke 每天写下"我爱公开演讲"，真的改掉了对演讲的恐惧；Armstrong 二十多岁写下"我想创办一家十亿美元的科技公司"，六七年后成了现实；当 CEO 之初害怕冲突，他又写下"我爱冲突"，把怒火练成推动产品的力量。访谈的主体是他过去几周的工作方式：每个关注领域都有一名首席 Agent 全天候运转，另有一名参谋长 Agent 统筹，下级 Agent 写代码、测试、追评审；公司内部还有一个"Coinbase Brain"，每名员工、每个团队、每个仓库都有一个大脑，夜里提炼教训、白天放进 Agent 的上下文。Armstrong 的判断是：十年后 99.999% 的交易将发生在 Agent 之间，稳定币轨道会成为 Agent 经济的实时支付轨道，而 AI 也必须像加密一样去中心化。收尾落在金融业本身：全部金融科技公司加起来只占全球金融服务收入的约 4%，其余 96% 仍在传统机构手里；他描出 AI 辅助投资的四级台阶，终点是"每个人口袋里都有一位私人银行家"。

Key Takeaways

  1. 写下来，是改写自己的办法。重复一句话能让它保持在注意力最前沿；Armstrong 靠写下"十亿美元公司"与"我爱冲突"，先后改写了职业轨迹与对冲突的恐惧。
  2. 给 Agent 一份工作，而不是一个提示词。首席 Agent 带自己的下级 Agent 干活、定期回来请示；按他的评估，这些 Agent 已有 L5、L6 级员工的水准。
  3. Coinbase Brain 是公司的操作系统。每名员工、每个团队、每个仓库都有一个"大脑"，夜里提炼教训；人的新工作是编辑大脑、对齐 AI，仍由人类做最终决定。
  4. 十年后 99.999% 的交易发生在 Agent 之间。Agent 经济需要自己的市场、货币与专家分工；信用卡先顶上向后兼容，稳定币轨道是真正的实时支付轨道。
  5. 金融业 96% 的收入仍在传统机构手里。真正的对手不是其他金融科技公司，而是惯性与代际更替；AI 辅助投资的四级台阶，终点是口袋里的私人银行家。

1. 写下来：从"十亿美元公司"到"我爱冲突"（约 0:00–4:50）

对谈开场于录制前的一段闲聊：Senra 与 Armstrong 在聊"给自己洗脑"——靠重复一句话，改掉自己想改的行为。Senra 提起 Shopify 联合创始人兼 CEO Tobi Lütke 上节目时讲的事：Lütke 从前害怕公开演讲，于是每天花大约十分钟写下"我爱公开演讲"，写了一个星期，如今真的爱上了演讲。Armstrong 认同这个做法，但给了一个更朴素的解释：这不是什么玄学，只是重复让一件事保持在注意力最前沿，白天就会注意到那些能让自己离目标更近一点的机会与练习；大脑像神经网络，每重复一次就是更新一次权重；祈祷与冥想也是同样的道理，几千年来人们一直知道重复能强化一条神经通路。

■ 写下来（Writing It Down）：把目标或想养成的信念反复写下来、让它保持在注意力最前沿的做法；Armstrong 认为它的作用机制是重复更新大脑的"权重"，而非玄学意义上的显化。

Armstrong 自己的例子更激进：二十多岁时，他写下"我想创办一家十亿美元的科技公司"——当时他连一家一百万美元的公司都没创办过，写下这句话"没有任何道理"。但他写了很多遍，开始留意各种想法与机会、不断尝试，有的成了、有的没成；约 29 岁搬到硅谷，六七年内，他成了十亿美元科技公司的创始人。

当 CEO 之初，他害怕冲突。CEO 每天都要做艰难的对话：两个人合不来、要开掉谁、要做硬决定——"你今天想让谁失望"。他开始写下另一句话："我爱冲突。我爱冲突。我爱冲突。"目的不是主动找人吵架，而是把冲突重新编码：冲突来临时，他能兴奋起来——"我正要做一件困难而有意义的事，让我们推进它"。产品评审会上觉得工作不够好时，他也学会了不再压着怒火、含糊其辞，而是直接说"这不够好，没达到标准，明天之前改掉"，甚至"也许你不是适合在这家公司工作的人"。事后常有人写信感谢他：大家都感觉方向不对，只是没人说破。

“I love conflict. I love conflict. I love conflict.”我爱冲突。我爱冲突。我爱冲突。

Senra 的回应是：领袖的情绪会传染。他在另一档节目 Founders in the Gym 里做的事，就是把创业者人生故事里的激情传给听众；他敬佩的人谈论产品的方式也一样——Enzo Ferrari、Steve Jobs，"像谈论爱人一样谈论产品"。Armstrong 接话：他想做到的标准，是"令人难堪的热情"——热情到让自己都觉得难为情，才算够格。

2. 每天四十条消息与"神圣的不满"（约 4:50–9:25）

Armstrong 对自己的产品永远不满意：Coinbase 应用里总有东西太慢、坏掉、不好用，他看在眼里就难受；他每天给 30 到 40 个人发消息，追问"这部分进展如何、那部分为什么还没动"，在公司里制造紧迫感；他觉得永远不会有"做完了"的一天，"按它本可以成为的样子，它还远远不够好"。这种不满他既当作压力，也当作燃料。

■ 神圣的不满（Divine Discontent）：大卫·奥格威形容最优秀的创造者的一句话——"我们对自己的表现抱有一种神圣的不满，它是自满的解药"；Armstrong 与 Senra 用它来描述顶尖创业者永不满足的状态。

Senra 讲了一个现成的例子：他的朋友、Ramp 联合创始人 Karim Atiyeh，对自家公司的一切都不满意，眼光极高，"不喜欢任何产品，也不喜欢任何创始人"。一次在迈阿密吃晚饭，Senra 拍着桌子让他说出一个他真正喜欢的东西——Karim 提到了 Profound 的创始人 James。Senra 回去一看：Ramp 在用 Profound 的产品，而 James 早已关注了 Founders 播客的账号；两人互关、私信，James 问"我们正要关一轮融资，你想投吗？"——"Karim 的神圣不满让我意外赚了一笔钱。"

内心独白是什么样的？Armstrong 说，他早上起来会有意识地选择自我对话：拉伸、运动、听 Founders、有声书，然后投入工作；事情不顺，他也不自我攻击，就是"我们得把它做得更好，动手吧"。即使大获成功，他也不怎么庆祝，马上问"接下来是什么"。从佛教"活在当下"的角度看，这或许算不上活在当下；但他觉得，沿着时间线回望，做那些想做的事，本身就是一种深层的满足。

满足感与幸福的区别，是这一节的收束：幸福是短暂的高潮，满足感是做有意义的工作、拥有有意义的关系、看到事情沿着长弧线进展、"对世界有用"带来的深层满足；人生的目标应该是满足感，而不是幸福；这场游戏不该容易——太容易就无聊了，要不断走出舒适区、迎难而上。

3. 人生的目标不是幸福，是影响力（约 9:25–13:49）

Senra 讲了一个他最喜欢的故事：Spotify 创始人 Daniel Ek 在 Founders 第一期节目里讲的——Dara Khosrowshahi 被邀请出任 Uber CEO 时还在犹豫，人在 Expedia 待得挺舒服；两人喝酒时，Ek 放下酒杯看着他说："从什么时候起，人生是为了幸福？这是为了影响力。这是世界上最重要的公司之一，你可以在上面产生影响。"结论是：优化影响力，而不是幸福。

“Since when is life about happiness? This is about impact.”从什么时候起，人生是为了幸福？这是为了影响力。

Armstrong 认同这个排序：Coinbase 的使命是建立一个更公平、自由、高效的新金融系统，而这件事"才完成了 1%"。Senra 追问内心感受：对产品质量的愤怒，到底是负面独白，还是动力？Armstrong 说，部分是竞争——跟市面上的产品比；部分是天生的建造欲——小时候玩《文明》与《星际争霸》，收集资源、建工业、扩张，"上瘾了，关不掉"。他现在不怎么玩游戏了，没时间；但生意与游戏挠的是同一个痒处，只不过游戏二十分钟一局，生意要以几十年为一局。

4. 文明科技树（约 13:49–17:20）

《文明》里有一棵科技树，Armstrong 办公室里就贴着一张它的打印件：从农业、文字、制陶起步，一路走到 AI、生物技术、金融市场、纳米制造，乃至尚未发明的未来科技。他觉得这个概念迷人：文明的进步就是这样一层层展开的，而他想做的，是给这棵树"添一片叶子"。游戏还有另一课：赢法不止一种——军事胜利、科技胜利、宗教胜利、外交胜利都可以。他举了一个小时候的对局：自己在一个大陆上与对手缠斗、耗尽资源，另一个大陆上却有一个文明正在坐大；于是他把已研发的技术送给较弱的一方，让那边的战事拖住未来的对手——"游戏里有这么多层次，很好玩，也能学到简单的策略"。

■ 文明科技树（Civilization Tech Tree）：游戏《文明》中从农业、文字一路研发到 AI 与未来科技的技术树；Armstrong 把它贴在办公室里，视作文明进步的路线图。

AI 让生意更像电子游戏了：一个人能做的事更多了，"一人十亿美元公司"可能还没出现，但已经很接近。Armstrong 创业之初是程序员，习惯单干；后来明白，要成大事必须找团队、赋能他人——对内向的极客来说这是另一套本事，也令人沮丧（"自己做明明更快"）。如今 Coinbase 约有 4,000 人，还可以更高效——而 Agent 团队 24 小时工作，这又是另一回事。Senra 顺势切入正题：过去几周 Armstrong 的推文让他想做整整一期节目——就读他的推文、请他展开。

5. 给 Agent 一份工作，而不是一个提示词（约 17:20–25:05）

第一条推文曾获得一两百万浏览：过去几周，Armstrong 改变了工作方式——每个关注领域都有一名首席 Agent 全天候运转，另有一名参谋长 Agent 统筹；每名首席 Agent 管理自己的下级 Agent，写代码、测试、追评审、与团队成员协调。推文的结尾是："在一个 Agent 经济与 Agent 金融正在成形的时代，推进生产力的边界，令人兴奋。我们都应该继续朝这个方向推进。"

■ 首席 Agent（Lead Agent）：为某一个关注领域全天候负责的 Agent，管理自己的下级 Agent，定期向人类请示重要决定；其上还有一名参谋长 Agent 统筹各条线。

转变的本质不在工具，在分工：几年前用 AI 是"给一个提示词、得一个回答"；现在是"给 Agent 一块职责或一个目标"，它带着自己的 Agent 团队去干，定期回来请示重要决定——"我看了数据、分析了它，五个最大的机会是这些，我建议先做前三个，同意吗？"Armstrong 点一下"是"，它就去执行。他负责对齐与引导，Agent 负责想出"做什么"。

“You give the agent an area of responsibility or a goal.”给 Agent 一块职责，或者一个目标。

质量如何分级：规划用最贵的前沿模型，子任务分给更便宜的模型，模型选择如今已自动完成——"连选模型这点开销都不该让人操心"。团队还大量使用开源权重模型，并针对内部数据微调：一个只会起草合规报告的小模型，在这项窄任务上跑赢了前沿模型——因为它训练了大量内部数据；而且更快、更便宜。

■ 开源权重模型（Open-Weight Model）：权重公开、可自行部署与微调的模型；经内部数据微调后，在合规报告起草这类窄任务上，Coinbase 的小模型跑赢了前沿模型，且更快、更便宜。

水平如何？按科技公司内部职级，Armstrong 认为这些 Agent 已有 L5、L6 员工的水准——"现在可以拥有一支无限的 L5 型员工队伍"。但 AI 不是人类："潜水艇不是鱼"——有些方面已远超人类（24 小时工作、即时回答、无限复制），有些方面还差得远（抓不住大局、有点拾人牙慧）；不过改进速度惊人。

6. Coinbase Brain：公司的操作系统（约 25:05–31:18）

除了微调窄任务模型，Coinbase 还在建一个叫"Coinbase Brain"的东西：每名员工、每个团队、每个 GitHub 仓库都有一个"大脑"。A/B 测试、用户研究、事故与故障、会议记录、代码评审、会计准则等政策文件都会被摄入；每天夜里，系统梳理这些材料、提炼关键教训、写进大脑；Agent 干活时把相关大脑放进上下文，产出就更贴合公司内部想要的样子。

■ Coinbase Brain：Coinbase 内部服务，为每名员工、每个团队、每个 GitHub 仓库各维护一个"大脑"，夜里从各类材料中提炼教训并写入；Agent 工作时把相关大脑放进上下文，以对齐公司内部的做法。

人的工作随之变了：越来越多是"对齐 AI"——编辑与培育大脑里的内容、解决矛盾（"14 个月前 David 这么说、Brian 那么说，到底按哪个？"）；人类仍做最终决定与最终代码评审。大脑的作用是让 Agent 一次到位、少来回。Armstrong 说，可以把它理解为公司的操作系统——公司的价值就是长期积累的做法、人与 know-how，把它形式化、编成代码；但人永远不会被完全取代："能不能只用 100 个人运营 Coinbase？我不知道。我的猜测是人数大致不变，但每个人能做的事多得多。"

Armstrong 现在有七八个首席 Agent，加一名参谋长；每名首席 Agent 下面又有三到五个下级 Agent；聊天窗口一多就失控——满屏文字、来回切换上下文。于是团队做了内部原型：一个按优先级排序的待办收件箱——像处理邮件一样，用键盘快捷键加语音听写快速批决定："是、否、否、是，这个改一下"；Agent 自己记录项目进展、决定找谁协作、找谁审批。这大大降低了认知负担。

■ 参谋长 Agent（Chief-of-Staff Agent）：统筹七八名首席 Agent 的 Agent；Armstrong 的待办收件箱原型按优先级排列各 Agent 需要他裁决的事项，供他用键盘快捷键与语音听写快速批复。

再往上一层，是副总裁级 Agent——"去巴西扩张吧，三个月后我来检查"，它自己组团队、见合作伙伴、签协议。但有些事还"提示"不出来：软件越写越容易，监管牌照却不能凭空提示出来，KYC 资金账户也一样。所以要想清楚哪些是护城河：流动性、成为美国流动性最好的交易所带来的网络效应、USDC 的网络效应。

7. Agent 经济：99.999% 的交易（约 31:18–38:46）

Agent 走出公司、彼此协作之后，需要自己的市场与金融基础设施：80 亿人协作靠市场、货币与专家分工，Agent 也一样。Coinbase 正在建 Agent 金融与支付轨道：信用卡先顶上（向后兼容——"给我买这双鞋、订这张机票"），而稳定币轨道会成为 Agent 经济的实时支付轨道。

规模会有多大？有人问 Armstrong，十年后全球 GDP 交易中有多少百分比发生在 Agent 之间，他答"99.999% 之类"——"转折点可能比我们想的来得更快"。逻辑是：Agent 可以无限复制、无需人类在环，交易量自然远超 80 亿人的经济——"就像人口从 80 亿变成 1 万亿，经济也会大得多"。Senra 接话：这正是他每天早上醒来想的事——如果每个 Agent 都能无限复制，经济理应大得多。

加密与 AI 在一起，真的更好：加密让金融系统去中心化、更自由，AI 也应该去中心化——最坏的版本是一两家大玩家掌握太多控制、带有偏见；去中心化的世界里，人人都有许多小型开源权重模型，可以自己定制；Agent 之间有选择——像选 FedEx 还是 UPS，选不同专长、不同供应商的 Agent，用金融市场把它们组装起来。

■ Agent 经济（Agentic Economy）：Agent 之间直接交易、协作的经济形态；Armstrong 认为它需要自己的市场、货币与专家分工，稳定币轨道是其间的实时支付轨道。

许多金融公司害怕 AI 碰自己的账户，怕它干坏事；Coinbase 的做法是建严格的控制与权限、客户始终掌控——目标是成为"最支持 AI 的金融账户"，同时安全可信。"我们在加密领域就是这么做的——最受信任的加密品牌，保管的加密资产比任何公司都多，AI 为什么不能一样？"这也是 Coinbase 的使命所在：用加密与 AI 这两项前沿技术，建设更好的金融服务，最终在世界上创造更多经济自由。

Senra 提起 Cognition 的 Scott Wu：Agent 接手一项任务、连续跑上整整一年，"能建一家公司"，相当于一个非常能干的人一年的工作量。Armstrong 接过这个类比，讲起正在听的一本有声书：波尔克总统想拿下加利福尼亚，派出一百名士兵，"去吧，弄清楚"，两年后他们带回了一个州——"高能动性"正是 Agent 这个词的核心：一个有能动性的模型。

■ 高能动性（High Agency）：无需人盯着、能自己推进目标、扛住不确定性的能力；Armstrong 认为这是选人、选 Agent 时最重要的特质，也是"Agent"这个词的核心含义。

8. 兴奋得睡不着，与害怕变化的人（约 38:46–42:39）

最让 Armstrong 惊讶的 Agent 成果，与供应商有关——他不愿点名是哪家供应商，"对它不好"：供应商太多，各自都有网络安全问题；Coinbase 想减少供应商、把软件收回自己手里：省钱，也更安全。网络安全事件"大约同比翻了一番"；业内把 2026 年 10 月叫"黑色十月"，每周都有多起事件。Coinbase 用前沿 Agent 在代码上线前逐行审查找漏洞；99% 的加密资产完全离线存储、与互联网断开、分散在世界各地，能抵御自然灾害乃至核战争。

尽管如此，建造本身让他"非常有劲"——"兴奋得晚上睡不着觉，'这太有意思了'，然后告诉自己'得去睡觉了'"；醒来第一件事想的还是这件事。他觉得自己很幸运，正处在职业生涯的黄金期，赶上建造的黄金时代。

“I’m just so excited I can’t sleep at night.”我兴奋得晚上睡不着觉。

为什么大多数人不像他们这么兴奋？Armstrong 的解释是进化心理学：对变化有所畏惧的人活得更久、繁衍更多；社会只需要一小部分人对变化兴奋，足以推动进步；人人都当创业者会"完全混乱"。Senra 提起他问过 Sam Altman 的事：Altman 说每周有十亿人用 ChatGPT——数字惊人，可"人人都在用 AI，人人又都讨厌 AI"，这种脱节让 Senra 困惑。Armstrong 补了一句：AI 公司到处宣扬"要抢走你的工作、杀死你"，消息传递确实可以更好；但更深层的原因是，人可以同时持有两种想法——有用，也有担忧。

他讲了一个 Amazon 董事的例子：问一屋子人"有多少人担心 Amazon 伤害本地商业"，许多人举手；再问"上个月有多少人用过 Amazon"，所有人都举手。恐惧与使用可以并存，这并不矛盾。

9. 预防原则与内部工具的去留（约 42:39–49:33）

历史上每次新技术都伴随恐慌，Senra 提起一个叫"悲观者档案馆"（Pessimists Archive）的账号：自行车刚出现时，人们担心孩子骑车跑远、举止放荡，报纸上甚至说骑太快会让"风把脸吹变形、定格住"——所谓"自行车脸"；小时候玩《毁灭战士》，母亲吓得要命；密码学刚出现时国会差点禁止民用——"恐怖分子会用它"，而 Armstrong 的反应是："我只不过是不想让人在咖啡馆读我的邮件。"人类就是这样，擅长把自己吓个半死。

■ 预防原则（Precautionary Principle）：在风险未明时先行立规、防止最坏情况的原则；Armstrong 认为它非常危险，因为想象中的风险往往不是真正的风险，过早立规可能扼杀整个行业。

Armstrong 的立场是：预防原则非常危险——应该先看看会发生什么，再立规矩；因为人预测未来很糟，想象中的风险往往不是真正的风险，或者小得多；立规过早可能"杀死整个行业"：核管会成立后，美国新建核电站的速度大幅放缓。有人会问："万一坏到世界末日怎么办？"他的回答是：历史上没有这样的先例，他对此表示怀疑；人类通常善于在问题真正出现时解决它。

DHH 与 Tobi Lütke 一起赛车，间隙里捣鼓 Omarchy；DHH 想买下 Shopify 内部的 AI 工具，觉得"比市面上任何东西都好"，Shopify 不卖。Karim（Ramp）也一样：内部 AI 工具按一张便利贴的原则组织——"能帮企业省时间或省钱吗？"——做得太好，决定对外卖，Router 就是其中之一。

Armstrong 的内部辩论与此相同：Coinbase 的内部编排框架（带优先级队列的那个）要不要对外？通用化比只供自家用"难 10 到 50 倍"——要适配每家公司的安全需求与计费偏好；开源也行，但会招来大量需求；而且这类编码编排框架迟早会有开源版本，"不该指望它成为巨大的收入来源"。但 Coinbase 开发者平台不同：为自家产品不得不接通每条链、做安全托管与质押基础设施，现在开放给全世界——"全球最大的七家银行"正在上面建稳定币钱包、支付与交易产品；他认为这会成为 Coinbase 的 AWS。

Senra 提起 Bending Spoons 的 Luca Ferrari 作对照：Bending Spoons 内部有一套自 2011 年起打磨的专有 AI 操作系统，越用越好，收购后直接叠加到被收购公司上；问他卖不卖，Ferrari 说"对别人没价值"，因为它完全按自家调校过，"不如直接把整家公司买下来、再把系统叠上去"。Armstrong 认同：卖 B2B 软件会招来无穷无尽的定制需求，而工具对自家最有价值，因为它"知道公司的一切"；眼下他更想克制——不再多开新产品线，专注已有的产品。

10. 金融业为什么还是 96% 属于传统机构（约 49:33–53:43）

生产率与收入的滞后，是 Armstrong 正在琢磨的一道题：生产率"实实在在地大幅提高"，收入却还没动——两种理论：滞后指标（六个月后会显现），与红皇后竞赛（大家都提速，相对位置不变）；Armstrong 押注前者——传统金融里拥抱 AI 的还不多。

Armstrong 的推文写道："我们有了会飞的汽车，该有一个现代金融系统了。"全部金融科技公司加起来只占全球金融服务收入的约 4%，传统金融机构占其余 96%。这个说法来自 Nubank 的 David Vélez，Revolut 的 Nik Storonsky 也向 Senra 确认过（"4% 到 5%，不到 10%"）；金融科技公司之间根本不是主要竞争——真正的市场在传统金融手里。Armstrong 给 Vélez 记了一功：是他把这一点讲清楚了。

为什么这么慢？世界有巨大的惯性：美国还有很多人用纸质支票付房租；人一旦学会一种做法、到了一定年纪就不再学新东西；改变往往要等一代人。还有一位即将上节目的大公司创始人（Armstrong 不愿具名）的观察：卖给科技创业公司只能做成小生意，他只卖给财富 500 强——"它们找到解决方案就以为完事了"，所以客户流失几乎为零。

转换需要"好得多"：东西只好一点点，人不会换；必须好得多、完全不同——就像人们放下谷歌搜索、改用大语言模型。Profound 的 James 说，工程部里大家换工具换得飞快——"今天用 Codex，明天叫 Code，后天又换一个"；但银行客户不会这样——"你得等这些人去世"。Armstrong 的判断：十亿多人正在用 AI Agent，他们会想在金融账户里也享受到 Agent 的好处；如果传统机构不给，Agent 甚至会帮用户完成转换。

11. 口袋里的私人银行家、机器人与收尾（约 53:43–60:28）

AI 辅助投资分四级。第一级——"买一股 Meta"，得自己指定资产、订单类型与价格；第二级——"买 Meta，占投资组合的 10%，分批建仓、逢跌加仓"，帮你在一段时间内达成目标；第三级——只给一个论点，比如"AI 的瓶颈在能源与数据中心"，或"颜值经济会很大，GLP-1 药物"——Agent 组出一篮子资产（礼来与诺和诺德是最大的 GLP-1 制造商），定好买入时机、止盈止损；第四级——没有自己的论点，但想跟一位"很会赚钱的聪明朋友"——看社区排行榜、跟单。走到这一步，"每个人口袋里都有了一位私人银行家"，而这从前只有富人才有。

■ 投资四级（Four Levels of AI-Assisted Investing）：Armstrong 划分的 AI 辅助投资的四个层级——指定一笔交易、分批建仓、按论点组篮子、跟单聪明朋友；层级越高，人需要给出的越少，Agent 给出的越多。

Senra 说，"Mickey Mouse"（实为 Micky Malka）在节目里说过类似的话——"移动互联网把银行装进口袋，AI 会把银行家装进口袋"；这句话原本是 Nubank 创始人 David Vélez 说的，Malka 在 Founders 节目里转述。

“Everybody now has a private banker in their pocket.”现在，每个人口袋里都有了一位私人银行家。

Senra 问 Armstrong 最希望 AI 做到、现在还做不到的事——人形机器人：AI 还不能在物理世界搬东西、不能坐飞机去另一个国家代表他；一旦机器人能建工厂、开矿、运营生物实验室，就是下一次跃变。Armstrong 共同创办的生物技术公司 New Limit 也在等这个时刻：现在人形机器人公司都在拿"咖啡师"做测试——"能做一杯意式浓缩吗？"还做不到；能做到了，New Limit 才会把它引进实验室。

收尾的推文回到开头的"神圣不满"：Senra 读出 Armstrong 的另一条推文——他花大量个人时间盯 Coinbase 应用的质量：资金被冻结却说不清原因、身份验证流程、应用启动速度、报错不说明问题、按钮点进去是死胡同；"修复正在随接下来几个版本陆续上线；如果你最近遇到过让你恼火的事，回复告诉我，我和我的 Agent 们都在看。"Armstrong 说，"Retail App Quality"（零售应用质量）正是他的一名首席 Agent；他先起草了这条帖子，Agent 审过后发出；Agent 汇总反馈、列出五大问题、开了五个工作 Agent，"其中几个已快上线"。Senra 问，多少改进来自他本人、多少来自 AI？Armstrong：这是协作——有时他推着 Agent 走（"我还是担心这件事，去弄清楚那个团队为什么还没做"），有时 Agent 带着发现来找他（"我翻了数据，客户最受益的几件事是这些"）。访谈至此收尾。

12. 讨论问题

1. "写下来"改写自己——如果让你每天写下一句关于自己的话，你会写什么？重复如何改变注意力，又在什么情况下会变成自我欺骗？

2. 首席 Agent 与 L5 员工——当 Agent 达到 L5、L6 水准，"给 Agent 一份工作"与"招一个人"在管理上还有什么本质区别？人类经理的工作会变成什么？

3. Coinbase Brain——把公司的 know-how 写进一个可编辑的"大脑"，谁有权改？当大脑里出现矛盾（两个人说过相反的话），该由谁裁决？

4. 99.999% 的 Agent 间交易——如果十年后几乎所有交易都发生在 Agent 之间，价格发现、信任与责任会发生什么变化？稳定币轨道够吗？

5. 金融业 4% 与 96%——传统机构 96% 的份额里，哪些是最难啃的（习惯、监管、信任），哪些会被 Agent 界面最先撬动？

6. 预防原则——Armstrong 说应该先看看会发生什么再立规矩；但核电站与加密的例子里，"先看看"的代价由谁承担？这条线该画在哪里？

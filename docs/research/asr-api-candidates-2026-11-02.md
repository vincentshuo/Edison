# 外部 ASR API 候选比较（2026-11-02）

## 结论

最低配 VPS 的首选方向应是外部异步录音文件识别 API。按当前可核验价格，腾讯云录音文件识别最适合先做候选验证：普通模型有每月 10 小时免费额度，后付费 1.75 元/小时；大模型 2.0 录音文件识别为 0.8 元/小时，且支持中文、英语、粤语及多种方言。百度智能云的音视频字幕模型适合中文字幕场景，后付费 2.5 元/小时，资源包最低可到 1.56 元/小时，但需要公开音频 URL，异步返回通常最长约 12 小时。OpenAI 的全球基准价格最低，但当前文档把带时间戳的 `whisper-1` 路径列为兼容性路径并计划于 2027-02-26 关闭，因此不能直接作为 Edison 唯一 Provider。

“性价比”取决于中文音频、是否需要词级/分句时间戳、音频是否允许跨境、每月总时长以及是否接受预付资源包。以下金额只计算转写，不含媒体下载、对象存储、失败重试和翻译。

## 淘汰与待补

- 阿里云相关录音文件识别页面当前可访问内容主要是导航壳或旧版说明；本次没有取得可核验的当前长音频价格和完整时间戳契约，因此不把它排入价格榜。
- 科大讯飞公开的“语音听写”接口是实时 WebSocket，单次会话最长 60 秒；没有在本轮取得适合 YouTube 长音频的异步文件转写价格与契约，因此不作为首批长音频候选。
- 百度和火山引擎的公共 URL 要求意味着 Edison 的媒体层需要临时、身份匹配且可撤销的 URL；URL 失效、服务端下载失败和 ASR 失败必须分开记录。

## 稳定 Provider 边界

Edison 的 Provider 输入保持统一：`video_id`、本地已获取且身份匹配的音频摘要、受控的临时上传/访问方式、语言提示和 Provider 配置版本。Provider 输出统一为 `source=asr_generated`、检测语言、`cues[]`（`start_ms`、`end_ms`、`text`，可选 `words[]`）、provider/model/version、远端任务标识和可分类错误。Provider 不接收 YouTube OAuth 或浏览器 Cookie，也不决定 Edison 的缓存、取消、重试和 preparation state。

长音频需要按 Provider 能力选择：腾讯云和火山引擎可直接提交小时级文件；百度需要公共 URL；OpenAI 需在 25 MB 上限下由 Edison 切片并修正全局时间偏移。所有候选都应先用同一组中文、英文、混合语言和长视频样本做 WER、分句/时间轴、延迟和失败率验收，再决定最终 Provider。

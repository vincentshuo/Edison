写过《It Doesn’t Have to Be Crazy at Work》的人，现在每天工作十六个小时。37signals 联合创始人、Ruby on Rails 创造者大卫·海涅迈尔·汉森（DHH）在 a16z 的这场对谈里，给出的理由不是焦虑，而是一种近乎上瘾的快感：智能体把他从写代码里解放出来，让他可以把全部精力花在最后 2% 的打磨上——几像素的偏差、一个菜单的位置、一次启动时的闪烁。他的新作品是一套叫 Omarchy 的 Linux 发行版，过去五六个月里他没有亲手写过一行它的代码，却通过智能体写了几十万行。整期对谈的核心论点是，Linux 过去三十年被嫌弃的那些毛病——终端、配置文件、看不懂的报错——恰恰是智能体最喜欢的东西；而 macOS 与 Windows 的鼠标点击式设计，在智能体时代反而成了障碍。由此展开的是一连串更大的判断：应用锁定正在瓦解，第三座移动平台的窗口二十五年来第一次打开，开源权重是防止双头垄断的唯一保障，而人类在软件这件事上可能已经迎来了超级智能——至少在它超过我们之前，品味与执着仍是人最后的护城河。

Key Takeaways

  1. Linux 的短板翻转为长处。终端、配置文件与详细的报错信息，正是智能体最喜欢的东西；macOS 与 Windows 的点击式设计在智能体时代反而成了障碍。
  2. 应用锁定正在瓦解。代码成本趋近于零，社区里一个人两周就能复刻 Lightroom；第三座移动平台的窗口二十五年来第一次打开。
  3. 品味比代码更值钱。写代码的门槛塌了，挑剔的眼光成了稀缺品；最后 2% 的打磨才是多巴胺的来源，也是他每天工作十六小时的原因。
  4. 小团队有了大公司的产能。六十人的公司借智能体获得数万人的产出，没有人事、会议与协调成本；野心随之膨胀到三年超过 macOS。
  5. 开源权重是诚实竞赛的保障。前沿实验室值得喝彩，但没有能本地运行的开源权重兜底，双头垄断会把整条价值链吸干。

1. 开场：从 Rails、Basecamp 到 Omarchy（约 0:00–3:58）

节目没有暖场，直接把三句最尖锐的话剪成冷开场：macOS 与 Windows 根本不适合智能体时代；到了今天还以为源代码里有护城河的人，是在自欺欺人；以及，明年就可能出现真正的超级智能。嘉宾是大卫·海涅迈尔·汉森（DHH）——37signals 联合创始人、Ruby on Rails 的创造者；主持人是 a16z 的普通合伙人马丁·卡萨多与阿尼什·阿查里雅。话题是他正在做的 Linux 发行版 Omarchy，以及智能体为什么会把整个操作系统的竞争格局重新洗牌。

卡萨多请他先勾勒一下背景，DHH 的自述很简短：做互联网软件大约三十年，其中二十三年在 Basecamp——那款项目管理工具发布时，Facebook 才刚上线一两天；Ruby on Rails 就是从 Basecamp 里抽出来的，后来支撑了 Twitter、GitHub、Shopify、Airbnb 与 Coinbase；Basecamp 如今已到第五版，Rails 到了第八版；五年前又发布了邮箱服务 Hey.com；二十五年里还写了四本书，包括《重来》（Rework）、《远程》（Remote）与《工作不必疯狂》（It Doesn’t Have to Be Crazy at Work）。然后是现在：他在做一个叫 Omarchy 的 Linux 发行版，用他的话说，这是“智能体时代第一款原生操作系统”。

■ Omarchy（Omarchy）：DHH 创建的 Linux 发行版，以 Arch Linux 为底、Hyprland 平铺窗口管理器为桌面，预装各家智能体命令行工具，主打“向智能体口述即可改系统”；其最新大版本为代号 Quattro 的 4.0 版。

他说，Omarchy 已经让几十万人从 Windows 与 Mac 转投 Linux，“Linux 桌面之年”这个喊了二十五年的预言终于成真。而他第一次在桌面上用 Linux，才是两年半以前的事——第一个发行版是 Ubuntu；服务器上用 Linux 倒是从九十年代就开始了。在此之前，他从 2001 年 Mac OS X 测试版开始就是坚定的 Mac 用户，直到苹果“走偏了路”。

2. Linux 的短板，成了智能体的长处（约 3:58–8:17）

阿查里雅问：Linux 桌面这一次到底为什么能成？是苹果与微软把生态搞砸了，还是 AI 与新技术让改系统这件事本身变容易了？DHH 说，两者都有，但真正起决定作用的是后者。他前一晚还在亲自试：直接告诉智能体“改一下我正在用的这个操作系统”，它就改了，而且改对了。“这太神奇了。”

对苹果的不满他并不否认：苹果沉迷于抽取别人生意 30% 的服务收入，“什么都不用创新也能赚大钱”；十年造一辆永远不卖的车、发布一款大 flops 的头显（他说的是 Vision Pro，戏称为“滑雪面罩”），都无所谓，反正有 30% 的抽成兜底。代价是与开发者的关系恶化——他本人就是为苹果辩护了几十年的开发者之一，最终忍无可忍才换到 Linux。但他承认，开发者的这点不满永远成不了气候：大多数人会继续忍受，因为卖商业软件就得上应用商店。

真正能让成群的人换系统的是智能体时代。DHH 的核心论点是，过去让 Linux 难用的三件事——终端太重、配置文件难懂、报错信息晦涩——恰恰是智能体最喜欢的三件事：智能体想要一切都有命令行界面，想要格式固定、可以直接编辑与更新的配置文件，想要报错里包含全部细节。“所有这些历史上的短板，就在今年，字面意义上翻转成了你想在电脑上装 Linux 的理由。”而苹果正在往相反的方向走：他说当天刚有消息，苹果让 macOS 与智能体协作变得更难，弹窗一再警告用户不要让 Claude 访问文件——“那它还能干什么呢？”

“Mac OS and Windows are just unfit for the age of agents.”macOS 与 Windows 根本不适合智能体时代。

Omarchy 过去五六个月的开发方式本身就是论据：他说自己没有亲手写过一行 Omarchy 的代码，却通过智能体写了几十万行。想换个开始菜单、挪一下时钟、给系统某个部分加个功能，用户只要说一句话，有时几秒钟、最慢几分钟就实现了。“这种体验极其令人上瘾。”他说，一旦真正泡进去五分钟，就没人想回去。过去四十年围绕鼠标点击建立的操作系统，在智能体时代行不通了：想在 macOS 上重设切换工作区的快捷键，只能一个个点进设置、逐个字段手工输入；“你没法用智能体做到这一点”——用电脑视觉去点，当然也可以，但“那很蠢”。他给苹果的处境起了一个名字：智能体时代的 AOL——一个围墙花园，里面放着缩水、受保护的东西，而大多数人想要的是开放的互联网。

3. 移动端：二十五年来第一次开窗（约 8:17–16:02）

卡萨多问：移动端在这个世界里会怎样？DHH 说，移动端必须以同样的方式改变，而这正是他对桌面端先行感到兴奋的原因：通向第三个操作系统的窗口，二十五年来第一次打开了。上一次有新操作系统在全球市场份额上打开缺口，是 2001 年的 Mac OS X；从那以后，窗口关上了。“今年，窗口开了。”

移动端一直在同样的格局下受苦：苹果与谷歌两家分走了别人生意里那 30% 的甜头。微软试过，花了几十亿美元做 Windows Phone，死掉的原因在很大程度上是没有应用——谁愿意换一部装不了 Instagram 的手机？DHH 说，正在变化的是这一点：Omarchy 社区里已经有人花了大约两周时间，把他唯一还留着 Mac 才跑的软件 Adobe Lightroom 完整复刻了一遍——不只是复刻，按他的说法，还比 Adobe 花了十五年、几千万美元做出来的原版更好。

把这个逻辑推到手机上：如果某个应用不存在，总会有人顺手把它“氛围编程”出来，因为智能体几分钟就能写一个；即便应用仍然不存在，智能体也可以直接替你完成你本来要打开应用去做的那件事。整个生态锁定的根基是应用的可得性，而应用的可得性正在被智能体瓦解。“软件开发的价格与难度已经跌到了零。”他的口号是：先拿下曼哈顿（桌面），再拿下柏林（移动）。

■ 氛围编程（Vibe Coding）：用自然语言向模型描述想要什么、由模型直接生成代码的开发方式；DHH 用它来说明，写应用的门槛已经低到任何人都能顺手复刻一个成熟产品。

卡萨多接了一句：五年前，建第三个移动生态的想法注定失败；现在，花一笔象征性的预算就能复刻排名前一万的应用，很多应用甚至不必复刻，因为智能体可以直接完成应用背后的那件工作。DHH 表示同意：“这完全在牌桌上了。”他还举了自己的例子：Omarchy 背后的非营利组织 Omacom 基金会已经筹集了约 2300 万美元的代币与捐款，为此要签的大量合同全部由智能体起草——没有打开过一次文字处理器；他甚至不再亲手签名，看一眼说“可以了，签吧”，智能体就把签名放上去、把文件寄出去。文字处理与 Photoshop 这一整类应用正在被智能体吃掉：Photoshop 曾经不只是一个应用，而是一门需要花几年才能学会的手艺；现在，你只要说“把左边那个家伙从照片里去掉”，照片就回来了，而且“看起来棒极了”。

接下来是速度的论证。DHH 说，本地模型现在每秒大约跑五十个 token，还不够让一切“活起来”；但 Fireworks 两周前在一场大会上演示了每秒 1500 个 token：四秒钟内，从一句“给我做个俄罗斯方块”到游戏跑起来，再加激光、加炸弹、加更大的怪物，“一切都在实时变异”。“这就是软件的未来：一切都将实时变异。”而那只是每秒 1500 个 token；“两年后，模型以每秒十万个、一百万个 token 运行时，会发生什么？”

4. 品味与最后 2%：为什么他每天工作十六小时（约 16:02–22:57）

卡萨多把话题转向一个看似矛盾的点：他一直把 DHH 看作手艺人——设计品味、人体工学都极好；他自己五十岁了还在玩《星际争霸》，最近有个补丁微调了幽灵兵的数值——那种玩了二十年的游戏里微小的调整。他问：软件是不是就是这些与代码行数无关的微小调整？长尾的设计选择，本身是不是一种护城河？变化是不是其实没有看起来那么大，只是写代码的那部分消失了，人仍然得爱软件、把品味灌进去？

DHH 说：“正是这样。”他觉得自己现在能把更多的品味、更多的愿景、更多的完美主义放进软件，因为从“发现几像素不对”到“想把它改对”之间的障碍已经塌了。“我现在看到任何问题——任何软件上任何不完美的地方——都只把它看作一个机会：把它打磨到完美为止。这就是我现在每天工作十六个小时的原因。”

“This is why I’m working 16-hour days right now.”这就是我现在每天工作十六个小时的原因。

这话出自一个写过《工作不必疯狂》的人之口，他自己也承认其中的反差：“现在完全就是疯狂工作。”原因是，如果你是那种完美主义、工匠气质的人，智能体等于给了你超能力——“这很上瘾，甚至可以说对健康与睡眠有点危险”。大多数氛围编程项目死在 80%：开头很有希望，做到八成、剩下一点毛边与 bug 时，人就失去兴趣了。但他说自己恰好相反：“我的全部多巴胺回报都在最后 2%。前 98% 我根本不在乎，我要的是最后那 2%。”只要还有人愿意一遍遍打磨到字面意义上的完美，这个时刻就“极其令人上瘾”，因为你仍然需要一双眼睛来把关，而眼睛下面是一整支没有协调成本的军队。

这也解释了他对小团队的执念。37signals 大约六十人，他从没想过拿它去换一家六千人或六万人的公司——“那意味着要跟六万人打交道，听起来像折磨。”但通过智能体获得六万人的生产能力，“现在，你引起我的兴趣了”：没有争吵、没有人事、没有委员会会议，只有他一个人以高带宽指挥一支执行着提纯过的愿景的智能体舰队。他引用了 Shopify 首席执行官托比·吕特克的说法：周末一个人加智能体，处在超光速状态；周一回到七千人的公司办公室，“戛然而止”，要应付人事、团队、汇报与经营公司的一切琐事。“用另一种方式，你不必应付这些，却能得到类似、甚至更好的结果。这就是这个时刻令人震惊的地方。”

■ 前沿实验室（Frontier Labs）：走在模型能力最前沿的少数几家商业实验室，本期对谈里主要指 Anthropic 与 OpenAI；DHH 认为它们值得喝彩，但不能没有竞争。

成本的部分同样出人意料。他说自己在 X 上开过一个玩笑：他工作了二十年，“现在有钱了”，能买多少 token 就买多少；实际上他只有三个 Claude 订阅，过去三个月里只有两周接近用满，大多数星期一个每月 200 美元的订阅就够了。“所以别告诉我，这个时刻只属于那些 literally 有无限钱的人。完全不是。”而且这还是最前沿的用法——“我们甚至还没谈开源权重模型，没谈便宜的模型，没谈本地运行与优化”。模型换代的速度也在加快：开发 Omarchy 的这几个月，他从 Opus 4.8 起步，随后一路换代到 Opus 5.5，“这两者之间的距离是巨大的”，圣诞节前可能还会有一次更新。

“Anyone who still thinks that there is a moat in source code, even millions of lines of it, are delusional.”到了今天还以为源代码里有护城河的人——哪怕是几百万行代码——都是在自欺欺人。

5. 超级智能已经来了吗（约 22:57–25:58）

卡萨多问 DHH 有没有自己的“超级智能测试”。他自己的测试是：每出一个新模型，就给它两万美元预算，让它自己买齐零件、给自己造一台能走路的机器人——家里不断有机器人零件与 OLED 屏寄来，“我不是在开玩笑”。到目前为止，模型离做到这一点还差得很远；一旦它真能自己下单、自己组装出一台能自主行走的机器人，“那一刻就是它到了”。

DHH 说他没有这样的测试，但他有一种感觉：就软件开发而言，“我们已经拥有超级智能了”。论广度，AI 比他认识的任何程序员都强；个别超级程序员在极窄的领域里还能胜过智能体一把，但把整体与速度合在一起算，“我现在 literally 可以通过提示、再稍微 steering 一下，造出任何我想造的东西”。

但他也承认，软件圈与硬件圈对时间表的感觉完全不同。他两周前刚去中国参观了宇树科技（Unitree）等机器人公司，听到的说法是四五年、甚至十年；而硅谷软件圈的人觉得超级智能“明年就可能到来并快速起飞”。做执行器与机械的人觉得“剥个洋葱其实很难”，做软件的人觉得一切近在眼前。至于马丁那个买零件的测试，模型目前的“决定”是不断给他家订购智能家居设备——“这其实很务实”，他调侃说，墙上的显示屏、会说话、能控制房子的那张脸，可能比真正能走路的机器人先到；“这就是你一不小心把自己变成回形针的方法”——给一个含糊的目标，优化人类幸福，然后砰的一声，你就成了回形针。

“We already have super intelligence.”我们已经拥有超级智能了。

6. 前沿与开源：两边都要（约 25:58–31:50）

阿查里雅问他怎么看前沿实验室与开源的关系。DHH 的回答是：开源与开放权重绝对必不可少，“我们需要竞争来让整个游戏保持诚实”。他说自己的职业生涯有两段都在为双头垄断瓜分一切而沮丧；只有大约 2000 年到 2009 年的互联网是个短暂的例外——最重要的平台完全开放、完全免费，任何人都能建任何东西、不必请求许可；然后移动平台来了，“游戏结束了”，又回到了那种得乞求许可、你的应用、乃至你的生意能不能存在都要别人点头的“专制经济学”。

■ 开放权重模型（Open-Weight Models）：权重公开、可以下载到本地硬件上运行的模型；DHH 认为它们是防止前沿实验室形成双头垄断、保持竞争诚实的关键。

他欣赏 Opus 5.5 与 OpenAI 的工作，但他说，如果结局是一个由政府用枪杆子背书的双头垄断，“那将是一场噩梦”。他把今天的处境比作九十年代的加密战争：当时离禁止公钥加密已经很近了，因为 NSA 等机构问“那我们还怎么监听一切”；“想象一下，如果没有加密，互联网会是什么样子——怎么做商业、怎么做通信？那将是对世界经济、世界发展与网络本身的巨大伤害。”他认为 AI 正处在同样的悬崖边上：已经有不少聪明人在说“也许政府应该直接接管它”。

好消息是，闭源模型内部的竞争比他见过的计算机产业任何阶段都激烈：不只有两家领先的实验室，SpaceX 的 xAI 也很接近，谷歌时而在局内、时而“不知跑到哪个岛上抽了点好笑的东西”，还有几家小实验室在啃食。更重要的是，开源权重模型也越来越能打：他估计 GLM 与 DeepSeek 的新模型在某些任务上只落后六七个月，“基准测试上有不少刷分，我不太信，但它们确实在局内”；而且这些模型可以跑在你自己的硬件上。半年前他还写文章说买快的个人电脑很蠢，因为当时能在本地跑的模型“什么都干不了”；“谢天谢地，我完全错了”——现在一台 DGX Spark 就能跑一个真正有用的模型，Qwen 的新 Flash 模型也完全可用，“一台能放在你桌上的盒子里装着智能，几千美元就能买到。这太不可思议了。”

但他强调自己不是“开源或死”的强硬派：“我要全部。”他为美国拥有两家领先的前沿实验室而喝彩，因为我们得以用它们建东西；前提是它们必须保持诚实，不能获得“无限印钞”的机会——没有竞争时，它们完全可以把 token 价格抬到每百万 500 美元，“而我们会付的，我们绝对会付”。他举了社交媒体与网络广告的先例：价值被谷歌与 Meta 两家分走，“吸走了在线广告价值链里 99% 的价值”，因为所有人都愿意为每一美元多换回一分钱。“这很反常。”在他看来，前沿实验室如果放任自流，“完全会这么干，因为这就是资本主义的运作方式——在大多数时候，这甚至是个特性而非 bug”。所以他的立场是同时持有两种想法：为开源权重欢呼，也为前沿的进展欢呼；“如果我们两者都有，对所有人来说一切都会更好”。

7. 三年超过 macOS（约 31:50–38:24）

卡萨多注意到，随着模型越来越强，所有人的野心都在爬梯子：五年前觉得神奇的东西，现在做出来只换来 X 上四十个赞；要继续获得多巴胺，就得把野心调得更高。他问 DHH：有什么是他过去想都不敢想、未来十二到二十四个月可能去做的？

DHH 承认，自己的野心膨胀就发生在这个项目上。去年刚开始时，他还是亲手写小 bash 脚本，“用我十根粗手指”，一边骂 bash 一边做，目标很小：给自己造一台更好住的电脑，一个苹果说了不算的地方；做给自己、五个朋友与网上几个人。结果有了几万人用，“挺好，有个不错的小开源项目，我有了一台更好的电脑，妙极了”。然后智能体来了，目标从“一台稍微好一点的电脑”变成了“天哪，我们 literally 可以造出完美的电脑”——四十年来他对电脑的一切想要的东西，现在差不多可以一个人做出来。“当然，跟朋友一起做更有意思，所以我邀请了几十万人一起来。”

于是有了他现在的“妄想”：三年之内，Omarchy 超过 macOS。“全世界只有 1.8 亿 macOS 用户。Mac 没有那么大。我知道在美国、尤其是在硅谷人人用 Mac 的地方看起来很大，但在那之外，它很小。1.8 亿——那甚至算不上一个 C 级互联网服务。”最大的服务有几十亿用户，“我们当然可以让 Linux 超过它”。这话听起来妄想，因为 Linux 人已经把“桌面之年”的预言喊了二十五年；但现在它正在发生，而且正在加速。最新的 Quattro 版本全面押注智能体——用智能体开发、把智能体交到每个人手里——已经有几十万人用上了。他甚至说，不妨十二个月后来检验：能不能在十二个月内把 Mac 拉下马？“我不会给它超过一半的概率，但我也不会排除它。”如果实验室里真有人认为，离递归自我改进造出“AI 超级神”只剩大约十二个月，“那我们肯定能把一个世界第二的操作系统踢下台”。

但他也划清了自己的野心边界：他不擅长那种宏大尺度的野心，“那是留给埃隆们去做的——让我们殖民所有行星，听起来很棒，给我在去火星的星舰上留个座就行”。他要做的是“在这个狭窄范围内极其凶猛地有野心”，把全部能量投进去；同时尽量不想十二个月之后的世界长什么样，因为那是“得重度 AI 精神病的最快方法”。他说自己更喜欢“AI 亢奋”——一种温和得多的版本：只专注于现在可能的事、现在正在造的东西。“你一旦开始想象两三四次模型跃升之后的世界，就会发疯：那人类还有什么存在的必要？我们都会变成回形针吗？”他认为，许多 AI 安全人士“发疯”正是因为整天只想最坏的情况：“如果你 1944 年坐在奥本海默旁边，问他‘你能想象五年后会发生什么吗？到处都是核废料的荒凉星球’——结果呢？原子弹是世界和平发生过的最好的事。我们 literally 得到了五十年的冷战，没有全面核毁灭。”未来极难预测，他唯一喜欢的预测是威廉·吉布森的那句：未来已经来了，只不过分布得还不均匀。

“The future’s already here. It’s just not evenly distributed.”未来已经来了，只不过分布得还不均匀。

这句引言定下了他的预测方法：不预测模型一年后会怎样——“摇一摇八号球，再问一次吧”——而是预测，如果每个人都能做到他现在正在做的事、看到他现在看到的可能，GDP 每年加速 3%、4%、5% 甚至 10%，“完全在可能范围之内”。

8. 文化战争、匿名黑客与九十年代演示文化的归来（约 38:24–52:15）

卡萨多说，这波 AI 浪潮里一个完全出乎意料、又令人欣喜的现象是：许多他们这一代人成长过程中仰望的人物都回来了，并且在指路——DHH 本人、埃里克·雷蒙德、约翰·卡马克——“这些过去三十年的中流砥柱”。他感谢 DHH 的一篇演讲（“软件已死，现在我们是建造者”）帮一代人度过了这段困惑的时期，并问 DHH 自己以谁为指路明灯、觉得谁说得对、值得更多人跟随。

DHH 说，他深深尊敬的、编程功力过硬的人，“100% 都已经完全入局了”，因为任何一个曾经艰难地做出过东西的人，都无法否认这些工具能加速工作。他也理解中间地带的焦虑：大多数程序员不像他那样经济上已经自由，他们靠多年苦功挣来了一个位置，突然担心“如果明天我们都不再是程序员了怎么办？我算是个好的 maker 吗？”对此应当有同情心——就像应当同情七十年代底特律的汽车工人、同情英国最初的织工卢德分子一样；但同情不等于回去：“我不想回到前工业时代，不想拿着自己的锄头、赶着一头牛去搞自给自足的农耕，也不想回到装配线。”只能向前穿过去，并想办法把所有人一起带过去。

■ 演示文化（Demo Scene）：九十年代黑客亚文化的一支——以极小的程序在有限硬件上演示图形、音乐与编程技巧，常见于盗版游戏开场与演示聚会；DHH 说它正在随 AI 一起归来。

至于眼下的“氛围之战”，他的描述毫不客气：有一大批人因为种种原因成了反 AI 的人，“不止一个，有十亿个”，整个社区都在对这种东西上瘾；如果把“最令人难以忍受的觉醒派”与“反 AI 的人”画一个维恩图，“它就是一个圆”。他认为这是一种讽刺：同一批人五年前手握文化权力、可以随时随地取消任何人，如今“鞋穿到了另一只脚上”。但他马上收回了半步：不应该掉进“全是部落之争”的陷阱，也不是“每个对 AI 不安的人都是蓝头发的白痴”，只是“每个蓝头发的白痴也都是反 AI 的”。他的结论是，不管感觉如何，只有一条路：向前穿过去；“没有人会自愿放弃这项技术，除非我们最后都变成 AI 仓库里一堆回形针。”莱特兄弟飞起来之后，世界就变了，“我们不会再用船运一切”。

他仰望的人，除了卡马克、蒂姆·斯威尼与米切尔·桥本这些共事过产品的老手，还有一个更奇特的现象：化名黑客的归来。安全圈一直有这个传统，现在它正在渗入主流：Omarchy 核心团队与 Omacom 基金会的员工名单里有两位化名人士，其中一位“胜过了”Quickshell 的创造者，另一位是团队里的艺术家；他通过基金会赞助的本地 AI 项目里也有化名者，比如 0x0 与 Mia’s Lab。这让他想起九十年代的 phreaker 文化与精英留言板：“我喜欢这种感觉，喜欢电脑周围重新有了这种能量，就像八九十年代那样——黑客与实验者突然又站到了所有事情的最前沿。”

他把这股能量与 X 联系在一起：X 是这场革命的“连接组织”，把艺术家、化名黑客与本地 AI 运动连在了一起；“如果那些蓝头发的强盗设法保住了它（在埃隆买下它之前），我们可能什么都不会有，最后只剩下一堆 LinkedIn 上的人类废话。”而九十年代演示文化本身也在归来：“现在最精致的演示出自一些随机的艺术家之手，他们根本不想做生意，纯粹出于对艺术的爱。”Omarchy 把这种美学直接做进了系统：招牌屏保就是 ASCII 艺术跑过四十种演示特效，“看起来完全像 1995 年演示聚会上的开场”；本地模型启动要花几秒甚至几分钟时，他又塞进去一个 ASCII 特效，“它有任何功能吗？完全没有。只是让你觉得自己在用一台很酷的电脑。”

■ 电子公告板（BBS）：拨号上网时代的在线社区，用户通过调制解调器拨号接入、留言与交换文件；DHH 十四岁时在卧室里运营过一个三线精英 BBS。

他说 Linux 发行版历史上总想做 Windows 的廉价翻版，“没人想要一个本来就不怎么样的东西的廉价复制品”，人们想要的是 bespoke、独一无二的东西。Omarchy 的美学就是九十年代演示文化的美学。他还记得盗版游戏开场里“Razor 1911 破解”的字样在屏幕上旋转，“那天我觉得自己酷了一点”；BBS 也是如此——XMODEM、YMODEM、ZMODEM、Kermit 这些协议，“为什么叫 Kermit，没人知道，但听起来很酷”。他十四岁时在卧室里运营过一个三线精英 BBS，丹麦电信垄断企业的人来装第三条线时，看到一个十四岁的孩子，“这一定是非法的”——“他完全正确。那完全是非法的，也完全地 awesome。”他至今还能听见 US Robotics 调制解调器 33.6K 接通的声音。“电脑应该有一点神秘感，应该很酷，不应该这么 polished。”他说，自己很爱苹果，但乔纳森·艾夫“基本上把电脑里的个性都用铝抛光掉了”；“那个时代结束了。我们正在把黑客带回来。”

节目的尾声回到他那间著名的办公室。卡萨多问：办公室是真的吗？那张美丽海景的照片？DHH 说：“非常真实。我现在不在那间办公室里，不然我就把镜头转过去给你看。”那间办公室在马里布，他每天发那张照片，“部分是为了我自己的满足感——我简直不敢相信我在这里工作”，“这是资本主义的战利品之一”。节目在一句“下次见面聊”里结束。

9. 讨论：六个问题

1. Linux 的三个短板翻转为长处，靠的是智能体喜欢命令行、配置文件与详细报错——如果下一代智能体改走视觉操作路线，这个论证还成立吗？Omarchy 的赌注押在了哪一种智能体身上？

2. 一个人两周复刻 Lightroom，是否证明“应用锁定已死”？复刻一个界面与功能，与复刻十五年积累的插件生态、色彩科学与专业工作流，是同一回事吗？

3. DHH 的多巴胺在最后 2%，大多数人的多巴胺在前 80%——如果打磨的快感只属于少数完美主义者，智能体时代的软件质量会更好，还是更参差？

4. “三年超过 macOS”的检验标准是什么？用户数、安装量，还是日常主力机的比例？如果十二个月后没有超过，Omarchy 的论证会失去什么、又会剩下什么？

5. 开源权重与前沿实验室“两者都要”，在现实中如何同时成立？如果前沿实验室的领先幅度越拉越大，开源权重兜底的说法会不会只剩象征意义？

6. 化名黑客与演示文化的归来，是互联网精神的复兴，还是一场怀旧？当年的 BBS 与演示聚会没有商业化压力，今天的“复兴”能走多远？
